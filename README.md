# Collegenator

Collegenator is a full-stack web application inspired by the classic Akinator experience, customized for our college community.

The application attempts to guess a person from our college based on a series of questions by using manually curated publicly available information collected from online sources.

Currently, the project is focused on UG-2 students.

## Features

- Akinator-style guessing system
- College-specific dataset
- Interactive question flow
- FastAPI backend
- Dynamic frontend interface
- Google Sheets integration for data handling
- Render deployment support
- Environment variable support for secure configuration
